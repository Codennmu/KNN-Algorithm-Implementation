# Machine Learning KNN Demo

A complete implementation of the K-Nearest Neighbors (KNN) algorithm using Python and Jupyter Notebook. This project demonstrates data preprocessing, model training, classification, evaluation metrics, confusion matrix analysis, and ROC curve visualization for different K values.

---

# Overview

The K-Nearest Neighbors (KNN) algorithm is one of the most fundamental supervised machine learning algorithms used for classification tasks. This notebook demonstrates the complete workflow of a KNN-based classification model including:

- Data preprocessing
- Feature selection
- Data visualization
- Model training
- Prediction and evaluation
- Hyperparameter analysis
- ROC curve comparison
- Performance metric visualization

The project is designed for beginners and students who want to understand the implementation and evaluation of machine learning classification models using Python.

---

# Features

- Complete KNN implementation
- Clean and beginner-friendly notebook
- Data preprocessing pipeline
- Model evaluation using multiple metrics
- Confusion matrix visualization
- ROC curve analysis for different K values
- Underfitting vs Generalization vs Overfitting visualization
- Accuracy, Precision, Recall, and F1-Score comparison

# Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Machine-Learning-KNN-Demo.git
```

Move into the project directory:

```bash
cd Machine-Learning-KNN-Demo
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the notebook:

```bash
jupyter notebook
```
